## 更新内容

1.1 给所有请求加了自动重试，这个改动对**读**是好事，对**写**是隐患：网络抖动时请求体已经到达服务端、只是响应没回来，客户端一重发，同一条记录就写了两遍。1.3 修正这个边界：

- **写请求不再自动重发**：读请求继续重试，写请求只允许发一次。
- **`unknownOutcome` 回读核对**：写失败时不再直接判定失败，而是回读一次服务端真实状态——已生效就按成功处理，避免「其实签上了却提示失败」。
- **`dedupeSchedules` 重复任务清理**：批量接口拉回任务后按业务键去重，命中时提示「已清理 N 条重复任务」。

这三条合起来解决的是同一个问题：**弱网下把「不确定」当成「失败」**。之前用户看到失败会再点一次，于是越修越多。

界面零改动，纯逻辑层。
