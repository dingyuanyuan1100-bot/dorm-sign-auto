## 更新内容

1.5 把动效体系搭起来之后，暴露了一个此前被忽略的问题：登录页的标题文字与上方 Logo 横向中心不重合，肉眼可辨。1.6 只做这一件事。

- **标题定位改为定值**：`left: 120px` + `width: 145px` + 文本居中，不再依赖字号与字距自然撑开的宽度。
- **Logo 与字形中心差归零**：对齐基准从「元素盒」改为「字形实际墨迹中心」，两个元素的中心线现在重合。

改动范围可以精确到字节：**JS 与 1.5 逐字节相同**（仅 `AndroidManifest.xml` 因 versionCode / versionName 变化），CSS 从 29,782 B 增至 29,800 B，+18 B；整包 3,355,672 → 3,355,673 B，+1 B。

## 已知限制（当时已确认，后续版本修复）

- **无应用内更新**：更新检测 2.0.2 才引入、2.0.5 才修好。装了 1.6 的设备收不到任何后续版本提示。
- 后端仍是 IP 直连、无 HTTPS；换后端是 2.0.0。
- **启动时序仍是两段**：静态闪屏与 React 侧 Splash 各一套，单套化到 2.0.8 才做。
- 本版只对齐登录页标题，其它页面的 1px 级偏差未系统排查。
