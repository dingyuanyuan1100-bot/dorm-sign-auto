## 更新内容

1.3 解决的是「写重复」，代价是把写请求的重试整个关掉了——不重复的代价是弱网下更容易失败。1.4 把这一刀切回来的部分，用更精确的判据补上，同时处理了另一个更显眼的问题：切页白屏。

- **`warmLink` 死连接探活**：浏览器认为连接还活着、socket 其实已经断了，这时发出的第一个请求必然失败并触发整条重试链，用户看到的是转圈到超时。改为发请求前先探活，断了就重建，首个请求不再必然踩空。
- **`runWrite` 安全重试**：写请求不是「一律不重试」，而是「只在确认未送达时重试」；结果不确定的情形仍交给 1.3 的 `unknownOutcome` 回读核对，不叠加第二次写入。
- **五页常驻单页改造**：原先 `screen` 是三元切换，页面整体卸载再挂载，React 首帧未出之前是空白，视觉上就是闪一下白。改为五个常驻层——`app / chrome / login-layer / overlay / pane`——切页只改可见性，DOM 不重建。

这版全部是结构与连接层改动，界面外观与 1.3 一致。

## 已知限制（当时已确认，后续版本修复）

- **无应用内更新**：更新检测 2.0.2 才引入、2.0.5 才修好。装了 1.4 的设备**收不到任何后续版本提示**，升级必须手动安装。
- 后端仍是 IP 直连、无 HTTPS；换后端是 2.0.0。
- **动效尚未建立**：缓动曲线、启动页入场、边缘右滑返回都在 1.5。
- **Android 12+ 冷启动白屏未修**：1.4 只解决 React 侧切页空白，原生窗口背景仍是系统默认，1.5 补 `colors.xml` / `styles.xml` 才修掉。
- 登录标题与 Logo 的中心仍有约 1px 偏差，1.6 处理。
