## 更新内容

1.5 给登录页加了「立即注册」，1.6 校准了标题间距，但注册态与登录态的入口是写死的：到了注册页仍显示「立即注册」，进了登录页也没有回退入口。1.7 把这个状态机补正，同时收掉页面上多余的引导。

- **注册 / 登录链接按状态切换**：当前处于注册态时入口文案变为「返回登录」，登录态才显示「立即注册」，不再出现指向自身的无效入口。
- **删底部两条引导文案**：与切换后的入口重复，去掉后底部留白收紧。
- **卡片宽度 420 → 404**：配合文案收敛，输入区与卡片边界重新对齐。
- **启动 Logo 飞行改为整体淡出**：原先飞行落位后还单独播一段收尾，视觉上像"落定又动一下"；改为与落位同时淡出，结束更干净。

包体从 3,355,673 B 降到 3,355,515 B，减少 158 B——删掉两条文案与卡片收窄后，CSS 与 HTML 的净减量抵消了新增的「返回登录」四个字。

## 已知限制（当时已确认，后续版本修复）

- **无应用内更新**：更新检测 2.0.2 才引入、2.0.5 才修好。装了 1.7 的设备收不到任何后续版本提示。
- 后端仍是 IP 直连、无 HTTPS；换后端是 2.0.0。
- **启动时序仍是两段**：静态闪屏与 React 侧 Splash 各一套，单套化到 2.0.8 才做。
- **时间选择仍是原生输入**：转盘式 `TimeWheel` 在 1.8 才上线。
- 设置页仍暴露「接口地址」一行，1.8 删除。
