大版本号跳到 2.0.0 不是里程碑式命名，而是因为这版动了三件根基：后端地址、账号标识与退出流程。

## 更新内容

- **后端整体迁移**：从 `http://47.116.135.24:8805`（IP + 明文 HTTP）切到 `https://175.24.230.58`（IP + HTTPS），是全项目第一次走加密通道。证书为自签 IP 证书，App 侧信任该地址。
- **去学号字段**：登录与注册不再采集学号，身份标识改由服务端绑定关系承担。
- **登录后自动弹绑定**：首次登录直接引导进入绑定流程，不再需要手动寻找入口。
- **退出二次确认**：退出登录增加确认弹层，防误触。
- **`ScreenScroll` 长列表滚动**：新增 `screenscroll*` 2 个样式类，长列表改为容器内滚动，页面整体不再被撑高。

原生层变化：**dex 与 resources.arsc 均有变化**，是 1.5 之后首次再动原生产物。

## 已知限制（当时已确认，后续版本修复）

- **更新检测尚未引入**：应用内更新 2.0.2 才上线、2.0.5 才修好。装了 2.0.0 的设备收不到后续版本提示，需手动换包。
- **IP 证书无域名**：地址仍是裸 IP，域名化要到 2026-11-12 的 nginx 切换才完成。
- 机型适配未做：不同分辨率下版式会变形，2.0.1 才引入等比缩放。
