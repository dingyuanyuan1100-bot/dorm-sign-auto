## 更新内容

前五版都在修「能不能用」，1.5 第一次处理「用起来是什么感觉」。这版也是**首次动到原生层**——1.0 到 1.4 的 `classes.dex` 完全没变，1.5 起 dex / `resources.arsc` 才首次出现差异（`aff46129` / `d9d28689`）。

- **流体缓动体系**：全站过渡从默认 `linear` / `ease` 换成统一的时长与曲线档位，位移与透明度不再各写各的。
- **边缘右滑返回**：手势层接管屏幕左缘，向右拖动可退回上一层，配合缓动收尾。
- **静态闪屏 + Splash 入场**：冷启动先出静态闪屏（`index.html` 内联，从 545 B 增至 1,810 B），随后 Splash 入场播放、Logo 飞行落位到首页标题位置。
- **登录页「立即注册」**：登录页补注册入口，不再只能靠找回流程绕进去。
- **Android 12+ 白屏修复**：新增 `colors.xml` / `styles.xml`，把窗口背景与主题色对齐品牌底色，系统启动窗口那一帧不再是白底。

## 已知限制（当时已确认，后续版本修复）

- **启动时序仍是两段**：静态闪屏与 React 侧 Splash 各一套，冷启动能看到「先静态图标、再播一遍入场」。单套化到 2.0.8 才做（样式全部内联进 `index.html`，并删掉 React 侧那套）。
- **登录标题仍有约 1px 偏差**：本版只做到「看起来对齐」，精确校正（left 120 / width 145 + 居中）在 1.6。
- **无应用内更新**：更新检测 2.0.2 才引入、2.0.5 才修好；装了 1.5 的设备收不到任何升级提示。
- 后端仍是 IP 直连、无 HTTPS；换后端是 2.0.0。
