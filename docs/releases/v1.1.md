## 更新内容

1.0 最大的问题是：连不上服务器时只有一句无从下手的失败提示，用户不知道该重试、该换网还是该等。1.1 专治这一条：

- **连接层自动重试**：请求失败不再直接抛错，先走重试，弱网下能自愈的就自愈。
- **报错带真实地址**：失败提示里显示实际请求的地址，排查「连的是哪个服务」一眼可见。
- **常驻网络条 `.netbar`**：新增 4 个 `netbar*` 样式类，顶部常驻显示连接状态。
- **吐司「重试」**：失败时给出明确的可执行动作，而不是干巴巴的失败。

样式与文案变化：新增 4 个 `netbar*` 类；新增「连不上 / 重试」两条文案；其余界面与 1.0 一致。

## 已知限制（当时已确认，后续版本修复）

- **无应用内更新**：更新检测 2.0.2 才引入、2.0.5 才修好。装了 1.1 的设备**收不到任何后续版本提示**，升级到 2.0.5+ 必须手动安装一次。
- 后端仍是 IP 直连（`47.116.135.24:8805`），无 HTTPS；换后端是 2.0.0 的事。
- 切页仍为多页结构，存在白屏；单页常驻改造在 1.4。
