## 更新内容

- **登录页两侧灰竖条**：手机浏览器打开时，登录页左右两侧露出底色，形成两条灰边。本版用 `loginbleed` 类把铺色扩到满宽，并给弹层遮罩补同色，消除边缘割裂。
- 新增 `loginbleed*` 2 个样式类，包体仅 +247 B。

## 已知限制（当时已确认，后续版本修复）

- **假清单仍在包内**：2.0.2 误打包的 `update/version.json` 未删，更新提示依旧永远「已是最新」。2.0.4 删除后变 404，2.0.5 才用绝对地址 + CORS 修好。
- 绑定弹层含 7 段说明文案、高 470 px，2.0.4 精简到 330 px。
- `≤2.0.4` 的安装包必须手动升级一次才能进入自动更新体系。
