## 更新内容

- **机型变形修复（等比 scale + `--stage-h`）**：页面按固定设计稿宽等比缩放，舞台高度用 CSS 变量 `--stage-h` 驱动，不同分辨率下版式不再拉伸变形。
- **返回键栈（`@capacitor/app`）**：接入 `@capacitor/app` 的 backButton 监听，按返回键先收弹层、再退页面，不再一键直接退出应用。这是首次在原生插件层面接入 `@capacitor/app`。
- **签发 IP 证书**：为 `175.24.230.58` 重新签发 IP 证书并部署，替换 2.0.0 临时使用的证书。
- **删 3 处副标题**：视觉降噪，页面层级更干净。

包体变化：**dex 变化**（`3bd06fff`，对应返回键栈接入）；构建产物新增 `web-V8jP797G.js`、删除 `cordova.js`。+5,754 B 主要来自 JS 增量与插件接入。

## 已知限制（当时已确认，后续版本修复）

- **更新检测尚未引入**：应用内更新 2.0.2 才上线。装了 2.0.1 的设备收不到后续版本提示。
- **手机浏览器端有灰竖条**：登录页两侧露底问题 2.0.3 修复。
- IP 证书仍非受信 CA 签发链的常规域名证书，域名化要到 2026-11-12 才完成。
