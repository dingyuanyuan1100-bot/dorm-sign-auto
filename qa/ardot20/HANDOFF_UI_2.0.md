## 6. 怎么操作画布（MCP 用法，照抄即可）

连接：`fileUrl = https://ardot.tencent.com/file/744609957794221`

### 6.1 关键 API

| 目的       | 工具                       | 说明                                     |
| -------- | ------------------------ | -------------------------------------- |
| 看当前页顶层节点 | `fetch_editor_state`     | 拿 pageList / topLevelNodes             |
| 读某节点子树   | `batch_read`             | `nodeIds` + `readDepth` + `properties` |
| 写入 / 修改  | `batch_edit`             | 一条 `operations` 字符串，DSL 见下             |
| 出图验收     | `capture_screenshot`     | 返回 PNG URL，`curl` 下载后看图                |
| 量布局找问题   | `capture_layout`         | `problemsOnly: true` 只报异常              |
| 找空位      | `locate_available_space` | 新画板定位用                                 |

### 6.2 `batch_edit` DSL

```
变量名 = I(父节点id, {type:"frame", name:"名字", ...})   // 插入
U("节点id", {属性: 值})                                  // 更新
```

- 文本：`type:"text"`, `content`, `fontSize`, `lineHeight`, `fontName:{family:"Poppins", style:"Bold"}`, `fill:"#1A1A1A"`  
  |  |  |  
  | --- | --- |
- 布局：`layout:"horizontal|vertical"`, `gap`, `padding:[上,右,下,左]`, `primaryAxisAlignItems:"SPACE_BETWEEN"`, `counterAxisAlignItems:"CENTER"`  
  |  |  |  |  
  | --- | --- | --- |
- 尺寸：`width:"fill_container" | "hug_contents" | 数字`，同理 `height`
- 填充：`fill:"#RRGGBB"`；**清空填充必须写 `fills: []`**
- 描边：`strokes:[{type:"SOLID", color:{r,g,b}, opacity:1, visible:true, blendMode:"NORMAL"}]` + `strokeWeight`
- 四角独立圆角：`cornerRadius:[7,7,2,2]`（左上顺时针）
- 绝对定位子节点：父 `layout` 不设（默认 NONE）时直接给子节点 `x` / `y`

⚠️ **两个坑**

1. 一次 `batch_edit` 里定义的变量名**在下一批会失效**，跨批必须用返回的真实节点 id。
2. 文字宽度要写 `"fill_container"` 才会自动换行；写 `"hug_contents"` 会单行溢出。

### 6.3 一次标准迭代

1. `batch_edit` 插入骨架（Frame → 内容 → 状态栏 → 头部 → 卡片 → 导航）
2. `capture_screenshot` 拿 URL
3. `curl -o xxx.png` 下载到 `qa/ardot20/`
4. 用图像识别逐项核对：文字是否裁切、卡片是否等宽、导航是否 4 项均匀、有无大块空白
5. 发现问题就 `U(节点id, {...})` 定点修，不要推倒重建
